# Security policy

This project is prerelease software. Only the newest published beta is expected
to receive security fixes.

Please do not disclose credentials, workspace contents or a working exploit in
a public issue. Use the repository's private vulnerability-reporting channel
when it becomes available; otherwise contact the maintainer through the npm
package owner profile and share only enough information to establish a private
channel.

Useful reports include the affected version, operating system, DSH version,
reproduction steps and whether the issue crosses a conversation workspace,
filesystem boundary or browser/Host trust boundary. Remove tokens, `.pen`
contents and personal paths from logs.
